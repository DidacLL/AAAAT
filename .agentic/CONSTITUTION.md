# AAAAT Constitution

These invariants change only through an accepted Class D owner decision, subject to higher Product Owner authority in docs/OWNER_INTENT.md.

- AAAAT is local-first; the user's workspace is authoritative.
- AAAAT remains fully human-operable without AI. Manual, AAAAT-assisted AI, and bounded external-AI paths work with the same ordinary user-owned information.
- Optional capability is not mandatory; non-core does not mean forbidden.
- VCVGenerator is core and works without a candidature or AI.
- Generated LaTeX/source is user-owned and portable. It exposes a LaTeX2e API, uses expl3 internally, and compiles through pdfLaTeX/pdfTeX. Alternate engines are not required.
- Canonical professional information, variants, and document overrides retain their established ownership boundaries.
- Every durable mutation uses an AAAAT application service.
- AAAAT protects its own state with explicit domain data, typed validation, narrow mutation paths, bounded operations, and renderer/process privilege boundaries.
- Provider output is ordinary operation-scoped input. AAAAT does not own external model reasoning, prompt interpretation, provider internals, network, or research behavior.
- Privacy projection controls operation disclosure; it may expose, omit, or locally replace values while authoritative literals stay local.
- The renderer remains sandboxed, context-isolated, and unprivileged.
- The AI domain remains provider-neutral; paid cloud access and developer credentials are not ordinary prerequisites.
- External integrations receive named product operations only, never generic CRUD, browsing/listing/search/query, arbitrary durable IDs, or scraping.
- AAAAT has no v1 compatibility obligation and remains maintainable by one engineer.

AAAAT does not become a general agent framework, workflow engine, generic plugin platform, mandatory cloud service, microservice system, provider marketplace, generic AI policy/security engine, or prompt-injection middleware. Do not add a subsystem, framework, extension mechanism, or runtime service if the Mission succeeds without it.
