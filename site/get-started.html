Your first minutes

Start with what you need.

You can save an opportunity or make a document. Neither needs an AI connection or a completed career profile.

Give your work a home

  1. Download AAAAT for your device and open it.
  2. Choose Create workspace and an empty folder you control. Your applications, reusable information and documents live there.
  3. Prefer to look around first? Choose Try with demo data in another empty folder. It contains fictional examples, separate from your own work.

Optional AI and PDF tools can be set up later. Choose Not now to start with the desktop workspace.

One useful starting point

Keep an offer. Find it again.

  1. Open Applications → New. Paste an offer, recruiter message or notes into the Source area.
  2. Add the details you know beside it. A fragment with little structured information is a perfectly useful application.
  3. Choose Save. Your original material remains available; no stage or completion checklist is required.

Return to Applications and search for the employer, role or another saved detail. Expand a cover for more context; choose Open / Edit to change the information. Select a Tag to read its shared meaning in the left monitor.

Another useful starting point

Make the document you need.

  1. Open Documents. Start a CV from a blank page, My information or a saved template. You can also create a cover letter.
  2. Edit the content, arrange sections and choose Save when you want to keep the document. A saved application is optional.
  3. Choose PDF when ready. If needed, use Settings → Documents → PDF setup, or select an existing compatible pdfLaTeX installation.

Editing remains available without PDF setup. Generated files are separate from editable documents, so later changes do not rewrite a PDF you already made.

Keep useful information. Come back to it.

Ordinary navigation keeps unfinished work available without silently saving it. Use Save to retain edits and Cancel to discard them.

The demo includes community, editorial, visitor services and other opportunities. Explore a complete application, a sparse recruiter message, reusable information and independent documents in whichever order helps you.
