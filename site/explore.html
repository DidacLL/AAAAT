The AAAAT guide · beginner to full control

Everything you can do with AAAAT.

AAAAT can be a simple place to remember job offers, a workshop for making CVs and cover letters, or a workspace assisted by the AI you choose. You decide how much to use. This guide starts with everyday tasks and then explains the more detailed controls you can use when you need them.

Start here · Finding your way

Find the right place in AAAAT.

After opening a workspace, AAAAT has three main places to work: Applications for opportunities and related notes; My information for professional details you will reuse; and Documents for editable CVs, cover letters and generated files. Settings is where you choose your workspace, AI connections, document tools and backups.

  1. Just installed AAAAT? On the welcome screen, choose Open demo to explore examples or New workspace to start with your own information. Each uses a folder you choose.
  2. Want finished PDFs or private AI assistance? On the first-run Make AAAAT ready for you panel, select PDF generation, Local AI or both, then Set up. Existing compatible PDF tools can be reused. AI remains optional.
  3. Where are the actions? Look in the fixed top bar for actions such as New, Save, PDF and the ⋯ menu; the actions change with the area you are using. Use the left navigation to switch areas.

To see a complete first-use walkthrough before continuing, use Get Started. You can return here at any point for the deeper controls.

Applications · From a few words to full context

Keep an opportunity and recognise it immediately.

Save a job offer or recruiter message

  1. Open Applications → New. Paste the copied offer, URL-containing message or note into Application text on the left. Add known details on the right if you wish.
  2. Choose Save. Keeping only a Source is fine; you do not need to invent an employer, pay or application stage. You can also save fields without pasting text.
  3. If a selected AI connection is available, Fill can suggest details and Tags from the pasted text. Review them or keep working manually. You are never required to use AI to save.

Search, inspect and change applications

  1. Return to Applications. Use Search to look through saved fields, Sources and Tags. Filters let you see Current, Archived or All opportunities, and narrow by recently added or changed entries.
  2. Select a cover to expand it and reveal more of the information you retained. The compact covers are for quick recognition, not mandatory status reporting.
  3. Choose Open / Edit to change a field, see Sources, attach Tags or create documents for this opportunity. Use the top-bar ← to go back to the collection.
  4. Use ⋯ → Archive to move an application out of the current collection without erasing it. Show Archived and choose Restore when you need it again.

When a recruiter calls: search the company or title, expand the matching cover and inspect your saved posting or notes. AAAAT does not demand that you maintain statuses such as Applied or Interviewing to keep this useful.

Applications · Keep the original

Remember where information came from.

A Source is the material you saved about an opportunity: a job posting, recruiter's email, application form, conversation, link or personal note. You can keep several Sources for the same application, so the original posting and later conversations remain available together.

  1. Open the relevant application and find Sources.
  2. Choose the add action. Select the material's type: Recruiter message, Job posting, Application form, Conversation, Link or Other.
  3. Give it a useful title; enter a URL if applicable; paste or write the content. Save the Source.
  4. Select a saved Source to read it, open Original to inspect retained text, or choose its editing action to correct details. You can remove a Source you no longer want.

Editing application fields or asking AI to extract useful facts does not replace the original Source. This is useful when a posting disappears or a recruiter describes the role differently later.

Applications · Deep personalisation

Keep your own kind of information—and make it stand out.

Job searches differ. A pilot may need flight hours; a nurse may need registration details; a software professional may care about technology and remote work. AAAAT's initial fields are starting points, not the full list you must live with.

Add a new field

  1. Open an application. Under Details, expand Information setup and choose Add information.
  2. Enter a clear Name, such as Travel required or Required certification. In Details, explain what the field means and how you want it used.
  3. Open Value format if you need something beyond simple text. Choose Short text, Long text, Number, Yes / no, Date, URL or Choice list. Choose One value or Several values as appropriate; choice lists can have their own choices.
  4. Choose Add. The field becomes available for application information. Enter the value relevant to the opportunity; leave unknown information empty.

Change meaning without losing control

  1. On an existing field, open its ⚙ menu and expand Edit field definition.
  2. Change its shared label or descriptive details and choose Save shared field. A field definition describes what this information means across applications; it is not just a decoration on one card.
  3. Use precise descriptions when you want AI to recognize unusual information. AI extraction works with your current fields instead of only a fixed developer list. Rewording a field can therefore change what you ask AI to recognize; check future AI suggestions after editing it.

Important distinction: renaming a field does not magically convert old values to a new meaning or change an application's underlying identity. Use clear, stable meanings for information you want to compare across opportunities. A field's label is not a hardcoded special command: AAAAT lets you define the information that matters.

Control what appears on an application cover

  1. Use the ☆ next to a field to include it among your favourites—the details that appear most prominently when browsing applications.
  2. Open ⚙ on a favourite field to move it earlier or later, and set Card prominence to Small, Regular or Large.
  3. Return to the application collection and see how the cards now emphasise your chosen information. This changes presentation, not the information you saved.

What each field control does

✎ Edit changes a value. ☆ Favourite affects what stands out on the cover. 👁 AI may use chooses whether the field is available for AAAAT's AI help. ✨ Ask AI requests help for that field. ⚙ Settings changes ordering, prominence and shared definition. These are independent choices: a field can be important to your own view without being shared with AI.

Applications · Shared Tags

Use a name once, and keep its meaning consistent.

Tags are useful for work arrangements, industries, qualifications, tools or anything else you want to recognize across multiple opportunities. A Tag has a Name, optional Aliases, a Definition and your own Notes.

  1. Open an application and find Tags. Type a name to search your existing Tags. Select one to attach it.
  2. To create a new Tag, enter its name and definition. Add aliases when other names should identify the same Tag; add notes if more explanation helps. Save it.
  3. Use the Tag again in another application. You are reusing the shared Tag, not creating a separate copy of its meaning.
  4. Return to Applications; hover, focus or select a Tag to read its meaning in the left-hand monitor. Edit a shared Tag when you want to update that meaning across its uses.
  5. With AI configured, choose Suggest Tags with AI. Review suggestions: existing Tags may be matched, while a proposed new Tag lets you edit its name, definition and aliases before choosing Create or Ignore.

Tags help you remember and retrieve information; they are not compulsory application stages or a project-management system.

Your career · Reuse without retyping

One professional history, different ways to present it.

Keep your experience in My information

  1. Open My information and choose ＋ New.
  2. Choose the useful information type or group. Add a title, such as your job role or project name; add organisation, dates, descriptions and other relevant details. Use the add-detail control for additional information.
  3. Choose Save. Repeat for professional experience, education, projects, skills, certifications, languages, contact details and whatever else is useful in your field.

You're not restricted to preset career categories. You can use your own groups and labels. This is your professional material, not a form designed for one kind of applicant.

Write different versions of the same experience

  1. Open a saved item and expand Saved variations.
  2. Choose New variation. Give it a meaningful name—for example Project leadership or Customer support focus—and write the alternate emphasis.
  3. Save it. Later, when making a CV, you can choose the current description or a saved variation for that CV.
  4. Use Edit variation to refine or remove an alternate version. The original professional entry remains distinct.

Keep your career preferences available

Use Career preferences to record the direction you're looking for, preferred locations, working arrangements, objectives and other useful context. Add or edit a preference directly. These are your stated preferences, not facts AAAAT should invent about you.

Choose what AI can know

On a professional-information item, use its 👁 control to choose whether AAAAT's AI assistance may use it. Career preferences have their own disclosure choices. Local storage, showing information in the interface and using it in an AI request are different decisions.

Documents · Full CV control

Build, tailor, save and reuse your CVs.

Start with what you already have

  1. Open Documents. Under New CV from, choose My information, Blank or a saved CV template; then choose New CV.
  2. Give the CV a useful title and edit it. Use ＋ Add section for sections such as Experience, Education or Projects.
  3. Within a section, use ＋ Add information to include an item from My information or Add custom content for text that belongs only in this CV.
  4. Choose Save in the top bar to keep the editable CV. Cancel abandons a new unsaved draft; closing an existing document does not silently rewrite it.

Change order, wording and sections

  1. Use a section's ••• menu to rename it, move it up or down, or remove it. Use the item's own controls to Edit, move or remove that content.
  2. For an item linked to My information, select Current version or an appropriate saved variation. Reset from My information restores the reusable wording; Open My information lets you inspect the original entry.
  3. Edit an item's title, subtitle, description, dates or link directly. Edits to this CV may intentionally differ from your reusable career history.
  4. Choose Save this edit for reuse when you actually want to keep wording beyond this CV: as another My information version, an update to the current My information entry, or—when applicable—an update to the source CV template.

Not every job application needs the same CV. Prepare a concise version for one role and a detailed one for another without losing the career information they share.

Adjust composition and PDF appearance

  1. Open a section's presentation options to choose Header, Main body, Secondary body or Footer. These are hints for document composition, not mandatory fixed columns.
  2. Under Document options, choose a language if useful, and edit PDF metadata such as Title, Author, Subject and Keywords. An optional Parser summary is also available.
  3. When more than one document presentation style is available, choose the PDF style that fits the result you want. Styles determine appearance; your CV sections and content remain yours.
  4. Choose PDF and inspect the rendered document. Return to the editor if you need a better result.

Reuse a whole CV layout

Under Document options → Save this CV for reuse, save a new reusable CV template or, for a CV started from a template, choose to update that template. Templates hold reusable content and composition; a PDF is a finished output, not the template itself.

Make a copy of something already rendered

In Documents, expand Generated files. Open a retained PDF, or use Edit a copy on a generated CV to start a fresh editable version. Your earlier generated file remains available.

Documents · Cover letters and applications

Write the letter you want to send—and keep it with the right job.

Write a cover letter yourself

  1. Open Documents → New letter to start without a particular application, or open a saved application and create a letter there.
  2. Edit the title, From details, body paragraphs and closing. The sender details used for this letter can differ from your reusable profile.
  3. Choose Save, then PDF when you're ready to produce the final letter.

Ask AI for a first draft, then make it yours

  1. In the letter editor, choose Context to see which professional details, career preferences, application information and Sources could inform the draft.
  2. If the letter belongs to an application, choose which Sources to include using the checkboxes. The application's document AI permission must also allow its documents to be used.
  3. Choose Draft. When a suggestion is ready, open Draft ready, read it and choose Use or Dismiss.
  4. Edit the resulting letter as you wish. Save and render it only when its content is right for you.

Create one application PDF

Within an application, create or choose its editable CV and cover letter. The application top bar offers PDF when a CV, a letter and a suitable presentation style are selected. This creates a combined application document. The individual documents remain independently useful.

Documents · PDF production from simple to fully custom

Create PDFs with pdfLaTeX—and own the source.

AAAAT lets you edit CVs and cover letters without learning LaTeX. To generate the PDF, it uses pdfLaTeX, the pdflatex executable supplied by a compatible TeX distribution. You can use AAAAT's guided setup, keep your own TeX installation, change the layout with a custom Blueprint, or export and edit the full LaTeX source project yourself.

Use the guided PDF setup

  1. At first launch, choose PDF generation in Make AAAAT ready for you and select Set up. Or return through Settings → Documents → PDF setup.
  2. If AAAAT detects an existing pdflatex, the dialog says Already available. Nothing else needs installing for this prerequisite.
  3. If it is missing, AAAAT opens the third-party installer or system software manager appropriate for your machine. Finish that installation on your computer, return to Settings → Documents and select Refresh or Check PDF.

On Linux, if the APT installation link does not open a software manager, install TeX Live using your distribution's software manager and then refresh AAAAT. MiKTeX is not a required vendor: any compatible installation supplying pdflatex can be used.

Already use TeX? Point AAAAT to your executable

  1. Open Settings → Documents → PDF setup. Expand Locations in Make AAAAT ready for you.
  2. Beside pdfLaTeX, choose Browse and locate the actual pdflatex executable (pdflatex.exe on Windows). Choose the executable, not the containing folder or a PDF viewer.
  3. Select Save. The same Locations area lets you edit Local tools and Downloads for future installations; existing installed files are not moved.
  4. Return to Settings → Documents and choose Refresh, then Check PDF if you want to verify document rendering.

Render an ordinary CV, letter, or combined application

  1. Open your CV or cover letter in Documents or from its saved application. Edit the content and choose Save.
  2. In a CV, open Document options to set document language, PDF metadata and optional parser summary. When more than one style is installed, use PDF style to choose its appearance.
  3. Choose PDF in the top bar. Open the output to check its layout and content; if you need a different result, return to the editable document and render again.
  4. For a combined document, open an application and select its CV and cover letter under CV + cover letter. Use the top-bar PDF when the required documents and style are available.

The editable document and finished PDFs are separate. Previously generated files and their source projects remain available even if you later change or remove the working CV or letter.

Advanced: make your own LaTeX Blueprint

A Blueprint controls the CV's LaTeX presentation: section arrangement, spacing, typography and page layout. It is not a CV template: a template saves reusable content and composition. A Blueprint lets you render the same CV through a different visual style without changing career facts.

  1. Copy the built-in Blueprint source into a text editor. Give your modified copy a name such as my-style.tex. The AAAAT LaTeX package documents the CV rendering commands Blueprint authors can use.
  2. Save the .tex file under blueprints inside AAAAT's application configuration directory (Electron userData), not inside your career workspace. Typical locations are %APPDATA%\AAAAT\blueprints on Windows, ~/Library/Application Support/AAAAT/blueprints on macOS, or ~/.config/AAAAT/blueprints on Linux. Actual configuration locations may differ on your computer.
  3. Open or reopen the CV editor. Under Document options, the PDF style selector appears when more than one style is available, listing AAAAT Default and compatible .tex files by name.
  4. Choose your new style, select PDF and inspect the output. If your LaTeX changes cause a compile error, edit the file and retry, or select AAAAT Default to use the built-in layout.

A CV section's Header, Main body, Secondary body or Footer placement describes its purpose. The selected Blueprint decides the actual arrangement; these roles are not fixed columns. AAAAT is not an in-app LaTeX code editor, so Blueprint development happens in the external editor you prefer.

Advanced: export, edit and rebuild the actual source

  1. Open Documents → Generated files, locate your PDF and choose Export source project. Application PDFs offer the same export through their application view.
  2. Choose a writable destination folder. AAAAT creates a separate copy of the retained project rather than changing the original used by the workspace.
  3. Open the exported folder using a text editor or your preferred LaTeX editor. The current generator writes entry files such as cv.tex, cover-letter.tex or application-document.tex, alongside aaaat.sty and the retained build/output files.
  4. To compile an edited project outside AAAAT, open a terminal in that folder and run pdflatex cv.tex, pdflatex cover-letter.tex, or pdflatex application-document.tex as appropriate. Use a compatible TeX installation and resolve any missing package errors from your TeX distribution.
  5. Keep your changed project and finished PDF wherever you like. Editing an exported project does not rewrite the saved working CV in AAAAT or automatically install a reusable Blueprint. To alter future AAAAT layouts, use the Blueprint folder and render-time PDF style selection above.

What to check when PDF generation fails

  1. pdfLaTeX unavailable: use Settings → Documents → PDF setup → Locations → pdfLaTeX to choose the executable, or complete the offered native distribution installation.
  2. Distribution installed but still not ready: return to Settings → Documents and refresh. On Linux, ensure the TeX Live packages providing pdflatex were actually installed.
  3. PDF Ready, but a document fails: read the TeX compilation message. It may identify a missing package, unsupported document content or an error in a custom Blueprint. Retry with AAAAT Default to distinguish a custom layout problem.
  4. Need the exact earlier result: open the retained PDF or export its original source project. A fresh render of today's edited CV may legitimately differ.

For operating-system installer details, see the installation guide.

AI · Your choice, not a requirement

Use AI in the way that suits you.

There are several equally useful ways to work. You can do everything manually; ask your configured AI for help inside AAAAT; copy an editable AAAAT request into an external text-capable LLM; or give a compatible external assistant access to specific AAAAT actions. These are choices, not levels you must complete in order.

AI · Configure and change models

Save several AI connections, choose which one works for you.

Set up the local model

  1. On the first-run setup screen, select Local AI and choose Set up; or open Settings → AI → Local AI later. The tested Granite model and its local runtime are an additional download of roughly 2 GB.
  2. Let setup finish. The installed local model can start with AAAAT. Existing independently configured AI connections are preserved.
  3. Open Settings → AI to see saved connections. Use the one you want for ordinary AI actions.

Add an AI you already use

  1. Open Settings → AI and choose New connection.
  2. Enter a Connection name you'll recognize, the Model, and its server Address. The compatible service must offer a supported chat-completions route. Enter an optional API key or token if that service requires one.
  3. Choose Save. AAAAT checks whether it can reach the service. A successful connection check does not guarantee that every response will be useful.
  4. Under Saved connections, choose Use on the connection you want. The selected connection is the one AAAAT uses for its ordinary AI assistance; saving several connections does not automatically assign a different model to every feature.

Edit, change or remove a connection

Each saved connection offers Edit for its name, model and address; Replace credential or Clear credential for authentication; and Remove when it is no longer needed. Select a different connection with Use. You can keep multiple models or providers available and switch between them without recreating your work.

Control automatic local startup

In Settings → AI → Startup, Run when AAAAT starts enables or disables automatic startup. The startup script is fully editable for users managing their own local model. Save applies your changes for the next launch; Cancel discards them; Use installed default restores the generated script. Most users do not need to edit it.

Move your connection choices to another computer

Expand Import or export AI connections in Settings → AI. Export saves connection names, servers, models and the selected default for later use. Import replaces the current connection settings after confirmation. Credentials are deliberately excluded, so add them on the new computer if needed.

AI · Deep personalisation

Change how AAAAT asks AI for help.

You don't have to accept every instruction AAAAT sends to a model. Its AI instructions editor lets you change the request for each supported AI action, rather than replacing one global prompt for everything.

  1. Open Settings → AI, then expand AI instructions.
  2. Open the action you want to change—for example, the action that extracts job information or helps draft a document. Its entry shows Default or Customized.
  3. Read Context AAAAT sends and Expected response. These explain the information available to that action and what kind of answer AAAAT expects.
  4. Change Effective instruction and choose Save. You can ask for a different emphasis, clearer wording, another language, or a style more appropriate to your work, provided the expected response remains usable.
  5. To undo your changes, choose Reset to shipped default. Expand Shipped default to compare the original instruction first.

Why the different prompts matter: asking AI to fill an application field is different from asking it to rewrite CV experience or draft a letter. Edit the instruction for the job you're doing. AAAAT still checks the returned information before using it, so changing the instruction too radically may produce suggestions you must correct or cannot use.

Want different information for different AI actions?

Use the field and professional-information 👁 controls described below, and the document Context view, to choose the applicable information. For an external assistant, you can edit the entire prepared request before copying. These choices are more precise than stuffing every detail into a single permanent prompt.

AI · Privacy and context

Decide what the AI can use—not just which model you use.

AAAAT makes separate decisions for what is saved on your computer, what is prominent on screen, and what may be used for AI assistance. You can keep information locally without including it in a request to a model.

  1. Application information: open an application and use the 👁 control beside an information field. This controls AI use of that shared kind of information. The ☆ beside it controls display prominence instead; the two are independent.
  2. My information: on a saved professional item, change AI may use this information using its eye control. Keep sensitive details out of AI context without deleting them from your profile.
  3. Career preferences: inspect or edit the career context you want to use, along with its AI disclosure choices. A career goal is not the same thing as a verified achievement.
  4. CVs and application documents: when working in a document linked to an application, use the document 👁 control to allow or disallow use of that application's documents with AI. This permission is separate from a field's local visibility.
  5. Before asking AI to write: choose Context in a CV or letter editor to inspect which professional details, career preferences and application details are prepared. In a cover letter, you can select which application Sources to include.
  6. Before going to another assistant: review the whole request in AI task. The text you see and edit is what Copy or Export uses.

For an independently hosted AI service, what you send is also subject to that provider's handling. Granting another tool broad access to your computer is a separate choice from what AAAAT itself shares through a bounded request.

AI · Help beside the task

Different AI actions for different moments.

1. Fill a new application from pasted text

  1. Open Applications → New, paste an offer, and choose Fill once your AI connection is ready.
  2. Review which empty fields were populated and which Tags were suggested. Existing manual values do not need to be overwritten to use the result.
  3. Edit anything incorrect, accept only the new shared Tags you actually want, and choose Save. The original pasted posting is kept.

2. Complete or revisit a saved application

  1. Open a saved application using Open / Edit. Choose top-bar Fill for missing AI-enabled information, or use a field's ✨ button for focused help with just that field.
  2. When AI suggests a value, choose Use this value, Edit or Dismiss as appropriate. If a result needs review, you can correct it, retry that field or dismiss it.
  3. For Tags, use Suggest Tags with AI. Match an existing Tag or edit the proposed new Tag before creating it. You remain responsible for whether a suggestion is worth retaining.

3. Improve selected CV wording

  1. Open a working CV. Edit an individual item, such as a professional experience, and find the AI action beside Title, Subtitle or Description.
  2. Request help for the specific text you want to improve. Review the suggestion rather than replacing the CV automatically.
  3. Keep the edit in this CV, or use Save this edit for reuse if you deliberately want it available in My information or a template.

4. Draft a cover letter with your chosen context

  1. Open a letter linked to an application. Use Context to inspect the information and choose which original Sources to include.
  2. Choose Draft; open Draft ready to read the proposed paragraphs.
  3. Select Use or Dismiss, edit the letter as you wish, then save and render it.

AI results are suggestions, not verified career facts. AAAAT preserves manual work and lets you continue working while assistance is pending.

AI · Universal copy-paste rendezvous

Work with the LLM you already use.

You might prefer ChatGPT, Claude, a local chat tool, or another text-capable LLM. It does not need to understand AAAAT, support an API, or have a special integration to help with an editable text request.

  1. Open the application you want help with. In the top bar choose ⋯ → AI task.
  2. Under Request, choose Application details when you want help with application information, or Interview when you want to work on interview-related text.
  3. Read and edit the complete request. Change the question, remove data you do not want to share or add your own instructions.
  4. Choose Copy and paste the request into your chosen LLM, or Export when you prefer a file-based handoff.
  5. Review the answer. Use the request editor's Result area and the available Import / Use action for the selected request. Interview text can be retained as an application Source; application-detail results can be reviewed for relevant field updates.

This manual route works with any text-capable LLM that can accept your request and return useful text. No provider-specific AAAAT plugin or API key is required. You still decide whether its output is accurate and worth saving.

AI · Advanced connected use

Let a compatible external assistant work with AAAAT.

Copy and paste is the universal path. If your external assistant supports the connection provided by AAAAT, it can also perform selected AAAAT actions without repeated re-entry. This is a different route with its own setup and permissions.

  1. Open Settings → AI → Connect another AI. Expand Connection setup for the information your assistant host needs.
  2. Follow the host's instructions to register the AAAAT connection. The required procedure depends on that host; it is not the same as choosing a model for assistance inside AAAAT.
  3. Use Use AAAAT with another AI to inspect reusable instructions; choose Copy or Export if you want to give those to the assistant.
  4. For a particular application, ⋯ → AI task can also let you allow or turn off future connected AI reads of its selected request. Review the text before granting access. Turning it off prevents further reads through that route; it cannot retract information already shared.
If you want the assistant to help with local setup

Under Connect another AI, there are separate permissions for bounded installer.ai and configurator.ai setup actions. Enable only the kind of setup help you intend to allow. These do not grant arbitrary access to your database, files or operating system, and an assistant host may have its own broader permissions outside AAAAT.

Connected support depends on what the external host can actually run. The manual editable-request route is always available when you do not want connected setup.

Your workspace · Keep control and recover it

Manage your local work with confidence.

Switch or create a workspace

Open Settings → Workspace. Choose New workspace for a new folder or Open workspace to return to an existing one. A demo workspace is separate from the information you choose to keep for yourself.

Back up and restore

  1. Open Settings → Backup and choose Back up. Select a separate folder for the backup and let AAAAT complete it.
  2. Store the backup in a safe place. When you need to recover it, choose Restore and select a fresh empty destination folder.
  3. If you have unsaved edits, review them first. Restoring does not mean overwriting the active workspace without an appropriate destination.

Your workspace backup and AI connection settings are separate. AI setup can be exported from Settings → AI, without carrying credentials in the portable connection export.

Remove information deliberately

Open Settings → Workspace → Reset. Choose what to clear: Applications, My information, or Applications and My information. Read the confirmation before proceeding. Generated PDFs and retained source projects are preserved by this reset, and shared Tags and settings remain.

Find the right settings page

The top selector in Settings switches between Workspace, AI, Documents and Backup. Use AI for connections, instructions, local-model startup and external assistants; Documents for PDF readiness and setup; Backup for safe copies; and Workspace for folders and Reset.

Help · Common questions

If something doesn't work as expected.

I saved an offer but cannot see the company on its cover.

Open the application and check which information you've saved. Mark the useful field with ☆, then adjust its order and Card prominence under ⚙. A card can represent only the Source or a sparse note; it need not have a title until you add one.

PDF isn't available.

Open Settings → Documents and inspect PDF readiness. Choose PDF setup to install a supported tool or use an existing compatible installation, then return to your document and choose PDF again. See platform installation help if the system's installation step needs attention.

My AI connection is saved but the model doesn't help.

In Settings → AI, confirm which connection is marked Selected, and check its address/model/credentials. Reachability is only a connectivity check. The model still needs to provide useful content for the particular action; try a simpler request, review AI instructions or choose another connection.

AI is missing something important—or uses information I don't want shared.

Check the relevant application fields and their 👁 controls, the professional item disclosures in My information, and document Context. If a field's definition is unclear, adjust its shared name or description under ⚙ → Edit field definition. For external LLM handoffs, edit the request itself before copying.

I need a different CV for another kind of role.

Start another CV from My information or a saved template. Choose the useful item variations, alter your sections and wording, and save it independently. You can keep the earlier CV and generated PDF.

Can I work with AI that AAAAT doesn't integrate directly?

Yes. Open an application and choose ⋯ → AI task. Edit and copy the request into any text-capable LLM. Direct integrations are another option, not a prerequisite.

Need a fuller control reference? Read the user guide and installation guide. For a problem in the software, use the public issue tracker with fictional example data rather than personal career information.
