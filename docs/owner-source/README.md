# Owner-source material

This directory preserves historical owner notes, prompts, conversations, visual assets, and related provenance. It is not an authority layer and does not independently create requirements.

Start with the root [Product Definition](../../PRODUCT_DEFINITION.md). Consult this material only when it helps explain an ambiguity or trace a claim. If it appears to conflict with the Product Definition, the Product Definition governs; if a consequential ambiguity remains, ask the Product Owner rather than inventing a reconciliation.
