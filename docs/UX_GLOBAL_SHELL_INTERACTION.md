The previous version was derived from a then-current renderer and several historical interaction notes. That made the shell vulnerable to implementation-derived navigation and to preserving assumptions that the product recovery has now rejected.

Current interaction authority is:

1. current explicit Product Owner instruction;
2. [`PRODUCT_DEFINITION.md`](../PRODUCT_DEFINITION.md);
3. [`PRODUCT_CONTEXT.md`](../PRODUCT_CONTEXT.md) for rationale;

The old content remains available in Git history for provenance/audit only.
